Prepared and imported cases run in the hosted demo. Live test generation requires a configured local server. Scope: one checkout requirement, not release certification.

AK LAB / 04↗BROWSER AUTOMATION
ZRHLON

Open-source adaptation · Applied AI

Jev Flight Agent

An adaptation of Browser Use’s Jev Ultrafast browser agent for natural-language flight searches. Jev selects typed operations and observed DOM targets; a separate language model supplies field text, and Playwright executes the actions. The loop checks stale page state and bounds execution.

Core agent, demonstrations and benchmarks by Gregor Žunič / Browser Use. My contributions: documentation, repository setup and UTF-8 compatibility fixes for Windows. Local search prototype requiring API keys and Chrome, not a booking service.
