Jev Flight Agent

A standalone browser agent for natural-language flight searches. Jev selects typed operations and observed DOM targets; a separate language model supplies field text, and Playwright executes the actions. The loop checks stale page state and bounds execution.

Local application requiring API keys and Chrome. Includes recorded demonstrations and search-result verification; it is a search prototype, not a booking service.
